### Task D: названия скидок - без немецкого дубля и цены

**Files:**
- Modify: `public/app.js:806-816` (chip в деталях рейса) и `:855` (label опций в модалке)

Формат description от API: `"Назва укр / Nazva deutsch | 108 eur (-10%)"`. Сейчас chip показывает name (до `|`, минус %-хвост) + price (после `|`). Нужно: только украинская часть названия, без цены.

- [ ] **Step 1: Хелпер** рядом со stripPct (app.js:~806):

```js
// Назва знижки: до "|" (без ціни), без %-хвоста, і без іншомовного дубля після " / "
const cleanDiscName = s => stripPct(String(s || '').split('|')[0]).split(' / ')[0].trim();
```

ВАЖНО: резать только по `' / '` (пробел-слэш-пробел), НЕ по голому `/` - чтобы не порезать «I-II група» и подобное.

- [ ] **Step 2: chip** (app.js:808-813) - использовать cleanDiscName, price убрать совсем:

```js
const chip = x => {
    const name = escTxt(cleanDiscName(x.description));
    const pct = `<b class="dc-pct">-${escTxt(x.percent)}%</b>`;
    return `<span class="disc-chip"><span class="dc-name">${name}</span>${pct}</span>`;
};
```

(Переменные parts/price удалить; CSS .dc-price можно оставить - не мешает.)

- [ ] **Step 3: опции в модалке** (app.js:~855) - `label: d.description` → `label: cleanDiscName(d.description)`. Проверить: discount_label, уходящий на сервер при брони (~1278), берётся из label выбранной опции - менеджер в TG теперь увидит чистое название, это ок и даже лучше.

- [ ] **Step 4:** `node -c public/app.js && node build-routes.js`, `npm test` (11 pass), проверка в браузере: детали рейса со скидками - «Особи, старші за 60 -10%» без «/ Senior ab 60» и без «108 eur». Коммит:

```bash
git commit -m "fix(discounts): назви без іншомовного дубля і ціни - лише укр назва + відсоток"
```
